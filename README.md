# Kokochi Studio — coming-soon page

This is the website for Kokochi Studio while the shop is being built. It shows the brand name, a short welcome, an email signup box, and a link to Instagram.

## How it works

- **The page itself** is the file `index.html` in this project.
- **Signups** go to Formspree. See them at https://formspree.io/forms
- **The website** is published by Vercel. Every time a change is saved here on GitHub, Vercel updates the live site by itself within about a minute.

## How to change the words on the page (no tools needed)

1. Open https://github.com/miamia-codes/kokochi/blob/main/index.html
2. Click the pencil icon (✏️) near the top right of the file.
3. Use Ctrl+F (Cmd+F on Mac) to find the words you want to change, for example "Pieces to wear".
4. Change only the words between the `>` and `<` marks. Leave everything else as it is.
5. Click the green **Commit changes…** button, then **Commit changes** again.
6. Wait about a minute and refresh the website.

If something looks wrong after a change, ask Claude to fix it — every past version is saved, so nothing is ever lost.
